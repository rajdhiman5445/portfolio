## Overview

Most note-taking applications enforce either rigid folder hierarchies or loose unstructured tags. *Archive Index* explores associative retrieval: nodes link together not merely through explicit links, but through semantic vector similarity and chronological co-occurrence.

## Key Features

- **Semantic Proximity**: Notes written on disparate days surface when they discuss related mechanical or philosophical questions.
- **Wandering Mode**: An interface toggle that hides search bars and lets you drift along graph edges, rediscovering forgotten reading notes.
- **Offline-First**: Embedded SQLite with local vector indices, ensuring instantaneous access with zero cloud dependency.
